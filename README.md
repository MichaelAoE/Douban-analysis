# 豆瓣影视数据分析与 BI 可视化
基于豆瓣影视公开数据集，完成从 MySQL 数据清洗、指标计算到 BI 可视化看板搭建的全链路数据分析项目。

## 项目简介
围绕影片基础信息、用户评分、评论内容三大维度，通过结构化 SQL 逻辑完成数据建模与核心指标统计，搭建交互式 BI 分析看板，挖掘影视内容分布规律、用户评分偏好、口碑影响因素等业务洞察。

## 核心功能
- 📊 **多表数据建模**：设计影片、评分、评论三范式表结构，建立索引优化查询效率
- 🧹 **全量数据清洗**：SQL 完成去重、缺失值处理、异常值筛选、字段格式统一
- 📈 **多维度指标计算**：分类、地区、年份等维度的统计分析与关联挖掘
- 📉 **BI 可视化看板**：交互式分析看板，支持维度筛选与层级下钻

## 技术栈
- **数据库**：MySQL
- **分析语言**：SQL
- **可视化**：BI 工具
- **分析方向**：用户画像、内容分析、趋势研判


## 核心结论
- 剧情、纪录片类影片整体评分显著高于商业类型片，口碑与票房导向分化明显
- 评分人数与评分分值呈弱正相关，高讨论度影片质量更稳定
- 近五年国产影片数量占比持续上升，评分中位数稳步提升

## 使用说明
1.  执行 `sql/create_table.sql` 创建数据表结构
2.  导入原始数据集后，执行 `sql/data_clean.sql` 完成数据清洗
3.  执行 `sql/metrics_calc.sql` 计算各维度分析指标
4.  使用 BI 工具打开 `bi/dashboard.pbix` 查看交互式看板
